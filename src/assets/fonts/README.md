# Bundled fonts

Downloaded on 1 October 2026 from the Google Fonts stylesheets already used
by this application. Font binaries are unmodified. Roboto includes all nine
upstream character subsets and normal weights 300, 400, and 500. The files
contain variable weights; fonts.css declares the range used by the app.

# Bundled fonts

Material Icons was downloaded on 1 October 2026 from the Google Fonts
stylesheet already used by this application. The font binary is unmodified.
Application text uses system fonts and requires no bundled text font.

Material Icons is distributed under Apache License 2.0; see
`MATERIAL-ICONS-LICENSE.txt`, obtained from
https://raw.githubusercontent.com/google/material-design-icons/master/LICENSE.

## Source binaries

- `material-icons-v145.woff2`: https://fonts.gstatic.com/s/materialicons/v145/flUhRq6tzZclQEJ-Vdg-IuiaDsNc.woff2

The stylesheet uses relative font URLs so assets work under the application
base href in development and production. To update these fonts, replace the
binaries and stylesheet together and retain their corresponding licenses.
